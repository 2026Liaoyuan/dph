# dph

Repository monitored by the dsh-superagent research prototype.

## Requesting work from the agent

Team members can ask the agent for work by mentioning it on GitHub:

1. Open an issue in this repository, or comment on an existing issue or pull
   request.
2. Mention the agent account, `@dPh-agent`, and describe the work you want done.
3. Include the context the agent needs: the file or behavior involved, and the
   result you expect.

The agent replies in the same thread to confirm the request, then investigates
and reports back with a pull request when the work is ready for review. A person
reviews and merges every pull request; the agent does not merge its own work.

Only accounts allowed by the agent's policy can request work.

Example:

> @dPh-agent Please add a setup section to README.md that explains how to run
> the project locally.
